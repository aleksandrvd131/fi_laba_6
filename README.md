# Лабораторная работа 6: Динамические структуры данных (Vector)

Реализация собственного динамического массива (`Vector`) на языке C и решение задачи поиска клиентов банка с минимальным балансом за указанный период.

## Структура проекта

- `models.h` — структуры даты (`date`), времени (`time`) и транзакции (`transaction`).
- `client.h` — структура клиента (`client`) со ссылкой на вектор его транзакций.
- `vec_tr.h`, `vec_tr.c` — реализация вектора транзакций.
- `vec_cl.h`, `vec_cl.c` — реализация вектора клиентов (с очисткой вложенных транзакций).
- `service.h`, `service.c` — парсинг файла, дат, расчет балансов, сортировка и бинарный поиск.
- `main.c` — запуск программы, чтение аргументов, вывод таблицы и клиентов с минимальным балансом.
- `test_vector.c` — базовые тесты вектора.
- `generate_tests.py` — скрипт для генерации тестового файла (>50 строк).
- `Makefile` — сборка и запуск.

## Сборка и запуск

Собрать проект:
```bash
make
```

Запустить тесты вектора и тестовый прогон:
```bash
make test
```

Проверить память через Valgrind:
```bash
make valgrind
```

Сгенерировать тестовые данные:
```bash
make generate
```

Запуск программы с параметрами:
```bash
./main test_data_50lines.txt 01.01.24 31.12.24
```
Или без аргументов (в интерактивном режиме):
```bash
./main
```
